Basic of CSS

font style

Font style is used to control the slant of text.

font family

Font family is used to specify the typeface of text.

font weight

Font weight is used to control the boldness of text.

font size

Font size is used to control the size of text.

text decoration

text decoration is used to add underline, overline, or line-through to text.

font color

Font color is used to control the color of text.

letter spacing

Letter spacing is used to control the space between characters.

line height

Line height is used to control the space between lines of text.
