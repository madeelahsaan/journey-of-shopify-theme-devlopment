# Kenya Coast Travel Project Report

## Project overview
This project creates a modern travel landing page inspired by a reference design for the Kenya Coast tourism industry. The website is designed to showcase destinations, stories, activities, seasonal travel inspiration, and newsletter signup for visitors interested in exploring the Kenyan coastline.

## Project goals
- Present the Kenya Coast as an attractive tourism destination.
- Highlight key beaches, activities, and local culture.
- Build a polished, responsive landing page for travel marketing.
- Demonstrate front-end design and user experience skills using a simple static web setup.

## Deliverables
1. A branded homepage with a hero banner and navigation.
2. Objective and mandate section describing tourism values.
3. Destination feature area with curated travel details.
4. Stories and insights cards for articles and travel inspiration.
5. Activity filtering section with interactive tab buttons.
6. Seasonal highlights and newsletter sign-up block.
7. Footer with useful links and business contact information.

## Structure
- `index.html` — page structure and content
- `styles.css` — styling, layout, responsiveness, and design system
- `script.js` — small interactive behavior for the activity filters and newsletter form

## Tools used
- HTML5 for structure
- CSS3 for layout and styling
- JavaScript for simple interactivity
- Unsplash images for visual content

## How to run the project
Open the project folder and launch a local server from the root directory:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
